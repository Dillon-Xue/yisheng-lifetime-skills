# yisheng-lifetime-skills

《一生的旅程》（*The Ride of a Lifetime*，罗伯特·艾格 / Robert Iger）蒸馏出的 5 个可迁移领导力 Skill。

由「一盏神灯」蒸馏流程产出，经三重验证（原文支撑 / 预测力 / 非常识）去重后归并为 5 个主题技能包。

## 包含的 Skill

| 目录 | 主题 | 适用场景 |
| --- | --- | --- |
| yisheng-crisis-decision | 危机中的决策定力 | 突发危机分拣、艰难拍板、压力/权力自净 |
| yisheng-talent-team | 识人用人与带团队 | 招人/提拔/培养接班人/解雇/并购人才整合 |
| yisheng-strategy-bet | 战略聚焦与大赌注 | 定方向、下重注并购、砍低回报项目、自我颠覆 |
| yisheng-innovation-disrupt | 拼死创新与主动颠覆 | 推动创新、打破陈旧假设、容忍失败、重塑激励 |
| yisheng-integrity-values | 诚信底线与价值观立身 | 价值观冲突、违规处理、以诚信立身 |

## 用法

每个子目录是一个独立 WorkBuddy Skill，将目录整体复制到  即可使用。

> 本书原则建立在超级巨头 CEO 的容错空间上，普通组织使用时应「降维」：在自己能承受的盘子里押注，而非照抄重金并购动作。
